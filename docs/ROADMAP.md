## 优先讨论

| 方向 | 解决的问题 | 完成的证据 |
| --- | --- | --- |
| 导入质量基准 | 截图与行程单的读取准确率没有量化 | 一组合成截图与行程单，按字段报告读取正确率，模型或提示变化时重跑 |
| 逐条录入与编辑 | 保存后的航班只能删除，不能修改 | 航班页可改日期、时刻、座位与舱位，改动后重新计算时长与行程 |
| 浏览器交互回归 | SSR 检查无法覆盖完整操作 | 导航、后退滚动、键盘、地球交互与分享卡片有稳定的浏览器检查 |
| 机场历史建模 | 同一代码可能经历机场搬迁 | 基于日期与坐标来源建模，去除特定档案的硬编码纠正 |
| 大档案性能 | 航线与标签在规模增长后可能成为瓶颈 | 可复现基准，按设备和档案规模报告测量结果 |
| 无障碍深化 | 地球上的地理内容需要对应的可访问表达 | 键盘流程、读屏说明与减少动态效果验证；面板已提供完整的文字记录 |
